# VenueWebAppProject

A venue management system.

The system handles the booking side of a venue while allowing operators to assign resources to each booking.

Each booking can contain:

- Room reservation
- Inventory items
- Internal staffing
- External staffing
- Event type

## Roles

### Customer

- Uses the website to make a booking

### Admin

- Has an account with admin rights
- Can approve and configure bookings

### Staff

- Can see their calendar
- Can see their working hours
- Can see bookings they are assigned to

## Project Status

Currently in development.

The current focus is building the initial database and application structure.
